## 2026-10-18 - @EricWang1358 - Stripe test-key guard no longer logs the key (#550)

- Kind: security fix (NFR-23); Refs #550, related #544.
- Found: a gate review reproduced on a real Spring Boot start that a non-test `STRIPE_API_KEY` with checkout enabled made Boot's bind-validation analyzer print the rejected value in full, so the guard against live keys wrote one to stdout and CloudWatch.
- Changed: `StripeCheckoutRuntimeProperties` replaces the field `@Pattern` with a derived `@AssertTrue isSandboxKey()`, so the report shows a boolean and the same reason text; accepted keys, the checkout-enabled gate and `toString` are unchanged.
- Verified: new `StripeCheckoutFlagConfigurationTest` cases fail before the change (the key is in the cause chain) and pass after; bootstrap Stripe tests, `ArchitectureTest`, checkstyle and SpotBugs pass.
