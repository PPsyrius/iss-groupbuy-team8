# Non-Functional Requirements Register

Every quality attribute the system is meant to have, as a scenario that can be checked, with where it is enforced and the evidence that it is. Companion to `docs/quality/quality-gates.md`, which holds the exact thresholds the pipeline enforces. Add or update a row in the same PR as the change.

Status: `enforced` (a gate or runtime control fails when violated), `implemented` (in code or config, verified by hand at least once), `unmet` (the measured or configured state does not yet satisfy the scenario), `documented` (designed, not yet in code), `target undefined` (matters, no measure set).

Scenario shape and worked examples: `.claude/skills/agile-evidence-capture/references/nfr-scenarios.md`.
