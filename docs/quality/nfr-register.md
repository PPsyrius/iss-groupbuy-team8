Measurable scenarios, controls and evidence. Gate thresholds: [quality-gates.md](quality-gates.md).

Statuses: `enforced` (control rejects violations), `implemented` (verified in code/config), `measured` (observed result), `unmet` (scenario fails), `documented` (agreed but unverified), `target undefined` (no measurable target). Qualifiers state verification limits.

Record the implementation delivered by each PR, not temporary merge/deployment status. GitHub tracks merges; release records track deployment. Retain environment-specific gaps when the scenario requires them. Scenario guidance: `.claude/skills/agile-evidence-capture/references/nfr-scenarios.md`.
