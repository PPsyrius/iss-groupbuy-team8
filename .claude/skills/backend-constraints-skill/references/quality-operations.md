# 测试、日志、可观测性、性能与交付

编写测试、审查质量、增加日志指标或准备交付时读取。

## 测试策略

- 领域层：纯 JUnit 单元测试覆盖不变量、状态机、边界值、失败路径，不启动 Spring。
- 应用层：mock 端口验证用例编排、事务前提、权限和事件；不要 mock 值对象/实体内部行为。
- Adapter：`@WebMvcTest`/契约测试覆盖序列化、校验、HTTP 状态、错误体和 Sa-Token 鉴权。
- Infrastructure：使用 Testcontainers 测 PostgreSQL/MyBatis SQL、唯一约束、锁/并发、Redis 序列化、RabbitMQ 发布消费；ES mapping/query 用真实兼容版本容器或专门集成环境。
- 端到端关键旅程：开团/参团、下单、库存竞争、支付回调、成团、取消、退款、重复消息和恢复流程。
- 并发测试必须验证数据库最终不变量，而不只验证接口成功数；包含重复请求、乱序事件、超时和部分失败。
- 测试数据独立、确定、可重复；禁止依赖执行顺序、真实生产账号或共享环境残留。时间、ID、随机数通过可控端口注入。
- 修复缺陷先添加能复现行为的测试；测试断言外部可观察行为，避免绑定私有实现。

## 架构与静态门禁

- ArchUnit 验证四层依赖、domain 无框架依赖、跨域不可访问 `mapper/persistence/internal` 包、Controller 不依赖 Mapper。
- 静态分析/代码搜索拦截字段注入、`System.out`、裸 `RuntimeException`、Controller 捕获通用异常、SQL `${}`、敏感日志和循环数据库访问；循环查询规则允许人工复核但不得静默忽略。
- CI 至少执行编译、格式化检查、单元测试、集成测试、架构测试、依赖漏洞与密钥扫描。主分支构建应可从干净环境复现。
- 对重要表 migration 做前向兼容和回滚演练；对事件/API 做契约兼容检查。

## 日志

- 需要日志的类统一 `@Slf4j`；使用占位符：`log.info("order created, orderId={}, userId={}", orderId, maskedUserId)`。
- INFO 记录低频业务里程碑和外部交互摘要；WARN 记录可恢复异常/降级；ERROR 记录需要处置的系统失败。高频逐条信息使用 DEBUG 或指标。
- 每条请求/消息贯通 traceId，重要异步事件带 eventId、aggregateId；不要依赖线程名作为关联键。
- 日志结构化并脱敏；禁止 token、cookie、密码、验证码、私钥、完整证件/支付数据和未裁剪请求体。日志字段控制基数和长度。
- 在能作出处置决定的边界记录异常一次，包含 cause；底层不要重复打印后再抛出。
- 安全审计日志记录登录、权限变更、商家操作、价格/库存变更、退款等主体、动作、对象、结果、时间、来源和 traceId，且防篡改、限制访问。

## 指标、追踪与健康检查

- 使用 Spring Boot Actuator/Micrometer；日志、指标、trace 三者通过 traceId/业务 ID 关联。
- RED：请求/消息 Rate、Errors、Duration；资源增加连接池、线程/虚拟线程、GC、堆、Rabbit backlog、Redis/ES/PG 延迟。
- 业务指标包括下单、支付成功率、库存拒绝、成团耗时、退款积压、outbox 滞留、消费重试/DLQ、ES 同步延迟。
- 指标标签只用低基数维度；禁止 userId/orderId/eventId 作为 metric tag。
- liveness 仅判断进程是否存活；readiness 判断是否能接流量。不要因短暂下游故障让 liveness 重启风暴。
- 外部调用和关键用例创建 span；记录安全摘要而不是完整 payload。告警必须可行动并有运行手册。

## 性能与韧性

- 优化以前测量：建立延迟分位数、吞吐、错误率、资源和数据量基线。性能问题优先检查 N+1、缺索引、无界结果、连接池等待和序列化大对象。
- 所有队列、线程池、连接池、批次、请求体、分页和缓存都有上限；超载时明确拒绝/降级，避免级联故障。
- 超时从入口预算向下游递减；熔断只用于确有意义的远程边界。fallback 不得返回会导致资金/库存错误的伪成功。
- 优雅停机停止接新流量，等待有限时间完成请求/消息，再释放资源。部署中验证 schema/消息/API 的滚动兼容性。

## 完成定义

- 代码位于正确域与层，模块依赖通过。
- 无循环查询/N+1；新增查询有边界、索引依据和批量策略。
- REST 状态、DTO、校验、幂等、状态码枚举和全局异常映射齐全。
- Sa-Token 登录/权限/对象归属校验覆盖成功与拒绝路径。
- 事务、一致性、并发与消息重复/乱序策略有测试或明确验证。
- 日志脱敏，关键指标/trace 可定位，配置无秘密。
- Maven 验证通过；未验证项和风险明确列出，不用“应该没问题”代替证据。
