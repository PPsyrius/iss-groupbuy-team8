# BlocBuy Frontend Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Bring `frontend/` from an empty directory to the walking skeleton (products list and detail, `/account` guard, logout, listing filter form) deployed to the dev CloudFront with a green Playwright smoke test, with the full quality toolchain, agent configuration, CI, and documentation trail in place first.

**Architecture:** Pure client-side React 19 SPA built by Vite 8 into static files, served from the existing hand-built S3 + CloudFront distribution at `/`, calling the Spring backend through the same distribution at `/api/*` (same origin, cookie session, no CORS). TanStack Router owns URL state and auth guards; TanStack Query owns server state through a client generated by hey-api from `contracts/openapi.json` at install time. Every response is a `Result<T>` envelope unwrapped in one shared `select`.

**Tech Stack:** React 19.3.0, TypeScript 7.0.2, Vite 8.3.0 (Rolldown), `@vitejs/plugin-react` 6.1.1 + `@rolldown/plugin-babel` 0.2.4 + `babel-plugin-react-compiler` 1.0.0, TanStack Router 1.170.36 / router-plugin 1.168.38 / Query 5.102.8 / Form 1.33.5, `@hey-api/openapi-ts` 0.0.0-next-20260824173136 (§12 note 19), valibot 1.5.0, Tailwind CSS 4.3.3, HeroUI 3.2.5, oxlint 1.83.0 + oxlint-tsgolint 7.0.2001, oxfmt 0.68.0, Vitest 5.0.1, Playwright 1.63.0, knip 6.35.1, Lefthook 2.1.14, MSW 2.15.0, pnpm 12.4.2, Node 24 LTS.

**Spec:** `frontend/docs/blueprint.md` (revision 2, 2026-09-15) and `frontend/docs/blueprint-review.md` (2026-09-15). Blueprint "Settled decisions" are binding; only its OPEN list is left undecided here. Deviations found on the planning day are listed in §12 and are never applied silently.

**Planning date:** 2026-09-16. Sprint 2: 2026-09-14 to 2026-09-25. Tier 1 targets the week ending 2026-09-20; tier 2 the week ending 2026-09-25.

Frozen for new tasks on 2026-09-25: new frontend tasks go in [backlog.md](backlog.md), the admin console in [admin-plan.md](admin-plan.md). Existing tasks are still ticked here.

## Global Constraints

- React 19.3, pure CSR, no SSR framework. Static files to the existing S3 + CloudFront (`https://d1b3np88z657cp.cloudfront.net`).
- TanStack Router with `@tanstack/router-plugin` file-based routes; plugin listed before `@vitejs/plugin-react`.
- React Compiler ON; convention: no manual `useMemo` / `useCallback` / `React.memo`.
- TypeScript 7.0.x (`typescript` package, `tsc` entry point). No programmatic compiler API until 7.1.
- Tailwind CSS 4.3; browser floor Safari 16.4+, Chrome 111+, Firefox 128+ (NFR, ADR 0001).
- HeroUI 3.2.x over raw React Aria Components. Exact version pins everywhere, no caret ranges.
- pnpm 12 via `packageManager` + Corepack; Node 24 LTS via `.mise.toml` and `.nvmrc`.
- TanStack Query 5 for server state. hey-api 0.99.x with `valibot`, `@tanstack/react-query`, and `msw` plugins. `baseUrl` overridden to `/`.
- `Result<T>` envelope types kept as generated; `data` unwrapped in one shared `select`; throw on non-2xx or non-OK `code`. No generator transform.
- Generated client is NOT committed. `pnpm gen:api` runs in `prepare`, first in `pnpm check`, first in `pnpm build`. Output dir gitignored and excluded from oxlint, oxfmt, knip.
- valibot only at `validateSearch` and forms. Never hand-write API response schemas.
- TanStack Form 1.x. MSW 2 handlers generated, loaded in Vitest `setupFiles` and behind a dev flag.
- Same origin: SPA at `/`, backend at `/api/*`. Backend has no context path; `/api/v1` comes from controller mappings. CloudFront does not rewrite paths.
- Auth: Google OAuth only. Login = full-page navigation to `GET /api/v1/auth/oauth2/google`. Probe `GET /api/v1/auth/me` → `{userId, nickname, avatarUrl}` (B4 landed in PR #89; it was `{loginId}` at planning time). Logout `POST /api/v1/auth/logout`. Unauthenticated → JSON 401 envelope. `GET /api/v1/products/**` anonymous.
- Auth state: `useSession` query, 401 interceptor that clears the session query and never redirects, `beforeLoad` guards read auth from router context; only guards redirect.
- Local dev: `docker compose up` → backend on `http://localhost:8589`; Vite proxy `/api` with prefix preserved.
- No `VITE_*` variables, no `import.meta.env`. One artifact promoted dev → prod. Future runtime config only via `/config.json` with `no-cache`.
- CloudFront hand-managed; changes go through the runbook, not `infra/`. SPA fallback via CloudFront Function on viewer-request of the default behavior. No distribution-wide custom error responses.
- Cache headers: hashed assets `public,max-age=31536000,immutable`; `index.html` `no-cache`; invalidate `/index.html` on deploy.
- `deploy-s3-dev` on push to `dev`, gated by the `frontend-dev` environment and `ENABLE_S3_DEPLOY`, OIDC role from the runbook.
- oxlint plugins `typescript`, `react`, `react-perf`, `jsx-a11y`, `import`, `unicorn`, `vitest`, `promise`; categories `correctness`, `suspicious`, `perf`; `--type-aware`. No `eslint-plugin-react-hooks`. Minimal ESLint only for `@tanstack/eslint-plugin-query` and `@tanstack/eslint-plugin-router` unless the oxlint JS-plugin spike succeeds.
- One gate: `pnpm check` = `gen:api` → `tsc --noEmit` → `oxlint --type-aware` → `oxfmt --check` → `vitest run` → `knip`.
- CI `ci-frontend.yml` mirrors `ci-backend.yml`; contract breaking-change detection stays in `ci-backend.yml`.
- Dependabot (not Renovate): `npm` ecosystem for `/frontend`, groups `tanstack` and `heroui`, daily.
- `frontend/AGENTS.md` conventions + Intent guidance block; `frontend/CLAUDE.md` = `@AGENTS.md`. Root `.claude/settings.json` hooks scoped to `frontend/**`. Do NOT run `intent hooks install`.
- ADRs in `frontend/docs/adr/`, Nygard format, from 0001, README index. Every PR: issue link, ADR names, `pnpm check` result or CI link, screenshot or Playwright trace for UI changes (blueprint-review D9).
- This session: no installs, no scaffolding, no Terraform or runbook edits. Only this plan and the ADR stubs are committed.

```ts
// One place that knows the backend Result<T> envelope. Generated types stay envelope-shaped;
// queries pass `select: unwrapResult` (or `select: (r) => unwrapResult(r).items`).
export interface ResultEnvelope<T> {
  code?: string
  data?: T
  message?: string
  errors?: unknown
  traceId?: string
}

// The backend ErrorCode enum encodes success as "0"; confirm against
// backend/blocbuy-common/.../ErrorCode.java during T1-07 and adjust this constant only.
export const OK_CODE = '0'

export class ApiError extends Error {
  readonly code: string
  readonly status: number
  readonly traceId: string | undefined
  constructor(args: { code: string; message: string; status?: number; traceId?: string }) {
    super(args.message)
    this.name = 'ApiError'
    this.code = args.code
    this.status = args.status ?? 200
    this.traceId = args.traceId
  }
}

export function unwrapResult<T>(envelope: ResultEnvelope<T>, opts: { allowVoid?: boolean } = {}): T {
  const { allowVoid = true } = opts
  if (envelope.code !== OK_CODE) {
    throw new ApiError({
      code: envelope.code ?? 'UNKNOWN',
      message: envelope.message ?? 'Request failed',
      ...(envelope.traceId === undefined ? {} : { traceId: envelope.traceId }),
    })
  }
  if (envelope.data === undefined && !allowVoid) {
    throw new ApiError({ code: 'EMPTY_DATA', message: 'Envelope has no data' })
  }
  return envelope.data as T
}
```

```ts
import type { QueryClient } from '@tanstack/react-query'
import { client } from './generated/client.gen'
import { meQueryKey } from './generated/@tanstack/react-query.gen'
import { ApiError } from './envelope'

// Non-2xx: throw an ApiError with the envelope's code/message when the body is an envelope.
// 401 additionally drops the session query so `useSession` re-resolves to anonymous.
// Never redirects: only route `beforeLoad` guards navigate.
export function installAuthInterceptor(queryClient: QueryClient) {
  client.interceptors.response.use(async (response) => {
    if (response.ok) return response
    let body: { code?: string; message?: string; traceId?: string } = {}
    try {
      body = (await response.clone().json()) as typeof body
    } catch {
      // non-JSON error body (e.g. ALB 403); fall through with defaults
    }
    if (response.status === 401) {
      queryClient.removeQueries({ queryKey: meQueryKey() })
    }
    throw new ApiError({
      code: body.code ?? `HTTP_${response.status}`,
      message: body.message ?? response.statusText,
      status: response.status,
      ...(body.traceId === undefined ? {} : { traceId: body.traceId }),
    })
  })
}

export { client }
```

```ts
import type { QueryClient } from '@tanstack/react-query'
import { meOptions } from '@/api/generated/@tanstack/react-query.gen'
import { ApiError, unwrapResult } from '@/api/envelope'

export type SessionState =
  | { status: 'anonymous' }
  | { status: 'authenticated'; userId: string; nickname: string | null; avatarUrl: string | null }

export const sessionOptions = () => ({ ...meOptions(), select: unwrapResult, retry: false, staleTime: 60_000 })

export async function sessionFromQuery(queryClient: QueryClient): Promise<SessionState> {
  try {
    const me = await queryClient.query(sessionOptions())
    return me.userId
      ? { status: 'authenticated', userId: me.userId, nickname: me.nickname ?? null, avatarUrl: me.avatarUrl ?? null }
      : { status: 'anonymous' }
  } catch (e) {
    if (e instanceof ApiError && e.status === 401) return { status: 'anonymous' }
    throw e
  }
}
```

### 6.4 Hook scripts

`.claude/hooks/frontend-fix.sh` (stdin JSON verified: `tool_input.file_path`; `$CLAUDE_PROJECT_DIR` exported to the process):

```bash
#!/usr/bin/env bash
# PostToolUse Edit|Write: format and autofix the touched frontend source file.
set -euo pipefail
input="$(cat)"
file="$(printf '%s' "$input" | jq -r '.tool_input.file_path // empty')"
[ -n "$file" ] || exit 0
root="${CLAUDE_PROJECT_DIR:-$(git rev-parse --show-toplevel)}"
case "$file" in
  "$root"/frontend/*|frontend/*) ;;
  *) exit 0 ;;
esac
case "$file" in
  */src/api/generated/*|*/routeTree.gen.ts) exit 0 ;;
  *.ts|*.tsx|*.js|*.mjs|*.cjs|*.json|*.css|*.md|*.yml|*.yaml) ;;
  *) exit 0 ;;
esac
cd "$root/frontend"
[ -d node_modules ] || exit 0
pnpm exec oxfmt "$file" >/dev/null 2>&1 || true
case "$file" in
  *.ts|*.tsx) pnpm exec oxlint --fix "$file" >/dev/null 2>&1 || true ;;
esac
exit 0
```

### 8.1 §14. SPA routing fallback (mandatory; supersedes §7.3)

Edit §7.3's heading to "(Superseded by §14)". New section:

````markdown
## 14. SPA routing fallback (mandatory for the frontend)

The frontend uses history-mode routing (`/products/<uuid>`, `/account`, `/auth/callback`). Without this function a deep link or a browser refresh returns the S3 OAC 403. Distribution-wide custom error responses are deliberately NOT used: they would also mask real `/api/*` errors.

Function source is versioned at `deployment/frontend/cloudfront/spa-fallback.js`.

```bash
# Runtime lives inside FunctionConfig (there is no --runtime option). A new function stays in
# DEVELOPMENT until publish-function is called with the ETag create-function returned.
FN_ETAG=$(aws cloudfront create-function \
  --name blocbuy-dev-spa-fallback \
  --function-config '{"Comment":"SPA fallback for BlocBuy dev frontend","Runtime":"cloudfront-js-2.0"}' \
  --function-code fileb://deployment/frontend/cloudfront/spa-fallback.js \
  --query ETag --output text)
aws cloudfront publish-function --name blocbuy-dev-spa-fallback --if-match "$FN_ETAG"
export SPA_FN_ARN=$(aws cloudfront describe-function --name blocbuy-dev-spa-fallback --stage LIVE \
  --query 'FunctionSummary.FunctionMetadata.FunctionARN' --output text)

# Attach to the DEFAULT behavior only (never to /api/*)
ETAG=$(aws cloudfront get-distribution-config --id "$DIST_ID" --query ETag --output text)
aws cloudfront get-distribution-config --id "$DIST_ID" --query DistributionConfig --output json > /tmp/dist-config.json
python3 - <<'PY'
import json
p='/tmp/dist-config.json'; d=json.load(open(p))
import os
d['DefaultCacheBehavior']['FunctionAssociations']={'Quantity':1,'Items':[{'EventType':'viewer-request','FunctionARN':os.environ['SPA_FN_ARN']}]}
json.dump(d,open(p,'w'))
PY

aws cloudfront wait distribution-deployed --id "$DIST_ID"
````

`deployment/frontend/cloudfront/spa-fallback.js`:

```js
// CloudFront Function (cloudfront-js-2.0), viewer-request on the DEFAULT behavior only.
// Extensionless paths and directory paths are served by the SPA's index.html.
// Paths with a file extension (hashed assets, favicon, config.json) pass through unchanged.
function handler(event) {
  var request = event.request;
  var uri = request.uri;
  if (uri.endsWith('/')) {
    request.uri = '/index.html';
  } else if (!uri.includes('.')) {
    request.uri = '/index.html';
  }
  return request;
}
```

The runbook's original §7.3 code rewrote `uri.endsWith('/')` to `uri + 'index.html'`; the frontend has a single `index.html` at the root, so both branches map to `/index.html`.

Why each CSP source: `script-src 'self'` (Vite emits no inline scripts; React Compiler output is in the bundle); `style-src 'unsafe-inline' https://fonts.googleapis.com` (React Aria / HeroUI set inline `style` attributes and `index.html` loads Inter from Google Fonts; revisit both in T2-11); `font-src https://fonts.gstatic.com` (the Inter files referenced by that stylesheet); `img-src https:` (product `coverImage` hosts are unknown until seed data is inspected; narrow in T2-11); `connect-src 'self'` (all API calls are same-origin); `form-action 'self'` (login is a GET navigation, not a form post); `frame-ancestors 'none'` replaces the older `X-Frame-Options` for modern browsers while `FrameOptions` covers the rest. `Preload: false` because the `*.cloudfront.net` domain cannot be preload-listed.

## 12. Deviations from settled decisions found on 2026-09-16

None are applied silently; each is planned as stated below and needs the owner's nod in PR-A review.

1. **React Compiler wiring.** Blueprint: "React Compiler ON via `@vitejs/plugin-react` 6 with Babel and `babel-plugin-react-compiler` 1.0.0". The plugin's current README no longer documents a `babel.plugins` option; the Babel path is `@rolldown/plugin-babel` + `reactCompilerPreset()` exported by `@vitejs/plugin-react`, with `@babel/core` and `babel-plugin-react-compiler` as optional peers (`^1.0.0`). Same decision (stable Babel compiler now), different carrier. Adds pins `@rolldown/plugin-babel` 0.2.4 and `@babel/core` 8.0.5. Evidence: https://github.com/vitejs/vite-plugin-react/tree/main/packages/plugin-react (README, "React Compiler" section) and `npm view @vitejs/plugin-react@6.1.1 peerDependencies`.
2. **`ensureQueryData` is deprecated.** Blueprint and TanStack Router docs use `queryClient.ensureQueryData` in loaders; TanStack Query 5.102 marks it (and `prefetchQuery`) deprecated for removal in the next major and documents `queryClient.query({ ...options, staleTime: 'static' })`. Plan uses the new call (T2-01, T2-02, T2-04). Evidence: https://tanstack.com/query/latest/docs/framework/react/guides/prefetching ("replace the use of the now deprecated `prefetchQuery` and `ensureQueryData`").
3. **`intent stale` is a maintainer command.** Blueprint and D7: run `pnpm dlx @tanstack/intent stale` in CI. The CLI docs describe `stale` as reporting whether *shipped* skills need review (for package maintainers), not whether a consumer's installed skills drifted. The plan keeps a CI job named `intent-stale` but implements the consumer-side check: diff `intent list --json` against the committed manifest, and verify the AGENTS.md managed block. Evidence: https://tanstack.com/intent/latest/docs/cli/intent-stale.
